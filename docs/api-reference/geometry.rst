************************************************
geometry (:mod:`MCEq.geometry`)
************************************************
.. currentmodule:: MCEq.geometry

The atmosphere models and the material target, the spherical Earth geometry
of the shower path, the site and parameter tables, and the geomagnetic
rigidity cutoffs of the full-sky solves.

:mod:`MCEq.geometry.msis21` needs the separately installed ``nrlmsis`` package
(``pip install 'git+https://github.com/afedynitch/nrlmsis2.1'``);
:mod:`MCEq.geometry.nrlmsise00_mceq` is bundled with MCEq.
