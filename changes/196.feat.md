The CUDA backend computes `int_off x + ri dec_off x` in one CSR SpMM kernel
that reads both matrices once for any number K of state columns. A batched
fp64 solve no longer costs K single solves (2D FLUKA operator on an RTX 3090,
K = 8: 10.5 to 2.3 ms per step). The modes of a 2D operator share one sparsity
pattern up to a few residual entries; the kernel keeps their union once (on the
Legendre release package the pattern arrays on the device shrink from 432 MB
to 5 MB and a fp32 single solve from 6.1 s to 4.5 s, with identical results).
