Data ships as packages listed in a YAML manifest (`mceq_db_manifest_v2.yaml`:
energy grid, sha256 and models per medium of each file):

- `mceq_base_air_1d_v2.h5`: energy grid, decays, continuous losses, FLUKA20251
  and SIBYLL23E; the new default `config.mceq_db_fname`;
- `mceq_extra_models_air_1d_v2.h5`: all other 1D models;
- `mceq_base_air_2d_v2.h5`: 2D FLUKA20251, 150 energy bins x 48 modes;
- `mceq_model_SIBYLL23E_air_2d_v2.h5`: 2D SIBYLL23E.

A model missing from the primary database is read from the package on the same
energy grid, downloaded on first use. `python -m MCEq.data.download` fetches
packages ahead of cluster jobs. Single-file databases still work. `pyyaml` is a
new dependency. See the *Data installation* page.
