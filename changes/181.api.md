Removed ``AIRSAtmosphere`` and the ``"AIRS"`` density model.  It could not be
used by anyone: it read three text files from a hardcoded ``~/OneDrive`` path
the package never shipped, and it called the base ``__init__`` last, so
``self.geom`` did not exist when ``init_parameters`` needed it (#71).  Use
:class:`~MCEq.geometry.density_profiles.TabulatedAtmosphere` with a CSV table
instead.

The ECEF impact-point geometry moved into :mod:`MCEq.geometry.geometry` as
``impact_point``, ``local_zenith_deg`` and ``surface_dip_deg``.
``MSIS00LocationCentered._impact_point`` and its MSIS21 counterpart now
delegate to it rather than each holding a copy; the two class trees stay
separate, the geometry does not.  Numerically unchanged, as the MSIS21/MSIS00
parity tests enforce.

``EarthsAtmosphere.calculate_density_spline`` now raises when any sampled
density is non-finite, naming the zenith angle and the height range, instead of
integrating ``nan`` into the splines.

``EarthsAtmosphere.nref_rel_air`` normalises the refractive index on the
density at the observation level rather than at sea level.  For the default
``h_obs = 0`` this is unchanged; for models whose profile does not reach sea
level it previously returned ``nan`` (a tabulated column starting at the
surface) or used air from below the ice
(:class:`~MCEq.geometry.density_profiles.MSIS00IceCubeCentered`).
