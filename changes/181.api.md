Removed ``AIRSAtmosphere`` and the ``"AIRS"`` density model. Use
:class:`~MCEq.geometry.density_profiles.TabulatedAtmosphere` with a CSV table
instead.
``EarthsAtmosphere.nref_rel_air`` normalises the refractive index on the
density at the observation level rather than at sea level.
The impact-point geometry is now shared from :mod:`MCEq.geometry.geometry` as
``impact_point``, ``local_zenith_deg`` and ``surface_dip_deg``, rather than
being duplicated in the MSIS00 and MSIS21 class trees. 
``EarthsAtmosphere.calculate_density_spline`` is no longer reimplemented per
backend.  A subclass that samples densities differently overrides the new
``_sample_densities(h_vec_cm)`` instead and inherits the path, the depth
integral and the spline fit.
