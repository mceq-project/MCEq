Removed ``AIRSAtmosphere`` and the ``"AIRS"`` density model.  It could not be
used by anyone: it read text files from a hardcoded path the package never
shipped, and it raised on construction (#71).  Use
:class:`~MCEq.geometry.density_profiles.TabulatedAtmosphere` with a CSV table
instead.

``EarthsAtmosphere.calculate_density_spline`` now raises when a sampled density
is non-finite, naming the zenith angle and the height range, instead of
integrating ``nan`` into the splines.

``EarthsAtmosphere.nref_rel_air`` normalises the refractive index on the
density at the observation level rather than at sea level.  For the default
``h_obs = 0`` this is unchanged; for models whose profile does not reach sea
level it previously returned ``nan`` or used air from below the ice.

The impact-point geometry is now shared from :mod:`MCEq.geometry.geometry` as
``impact_point``, ``local_zenith_deg`` and ``surface_dip_deg``, rather than
being duplicated in the MSIS00 and MSIS21 class trees.  Numerically unchanged.

``EarthsAtmosphere.calculate_density_spline`` is no longer reimplemented per
backend.  A subclass that samples densities differently overrides the new
``_sample_densities(h_vec_cm)`` instead and inherits the path, the depth
integral and the spline fit.  The MSIS00, MSIS21 and tabulated classes were
four copies of that bookkeeping; the azimuth-averaged MSIS00 path also gains
the non-finite-density guard it was missing.
