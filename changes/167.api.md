Physics-relevant default changes in ``mceq_config``:

- ``loss_stencil_method = "expfit_low_upwind2"`` (was ``"expfit"``): the
  continuous-loss derivative operator now uses the exponentially-fitted
  interior stencil with a monotone second-order upwind low-energy
  boundary layer. This is the validated configuration used for the v2
  paper results; it removes the low-energy "boundary cliff" of the pure
  expfit operator (essential for EM cascades on the 1 MeV grid, and it
  only touches the lowest ``loss_stencil_low_upwind_rows`` energy rows).
- ``average_loss_operator = False`` (was ``True``): loss-operator
  averaging is no longer needed for stability with the upwind stencil
  and biases EM shower maxima (number-Xmax ~+2.7 g/cm^2, Nmax ~5.6%).
  Set ``True`` only to reproduce pre-2026-06 historical numbers.
- ``muon_helicity_dependence = False`` (was ``True``): the helicity L/R
  muon variants add semi-Lagrangian rows without diagonal damping that
  destabilize EM cascades. Re-enable for muon-flux work that needs
  polarisation-dependent decay spectra.
