Added ``docs/examples/ERA5_density_spline.ipynb``, which converts an ERA5
netCDF download into MCEq tables -- one longitude/latitude grid per day --
runs MCEq on them, compares the result against NRLMSISE-00, and maps and
animates global column depth.  It starts from ERA5's surface geopotential, so
every column is integrated from where the ground actually is rather than from
sea level, aggregating the orography over each grid cell instead of sampling it
at one point, and it shows the shower impact point tracking from the detector
at zenith 0° to the antipode at 180°.
