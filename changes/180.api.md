Layered the solver and configuration layers, and moved the golden harness onto a
per-species flux metric.

- `MCEq.solvers` is a package running one ETD2 algorithm on every backend. The 18
  `solv_*` entry points are replaced by `solve_etd2(..., backend=)`, φ is written
  once and lowered to numpy, C and cupy from one formula table, and fp32 is a
  dtype rather than a kernel family. `MCEq.solvers` no longer re-exports 31
  private helpers or the incidental imports (`np`, `sp`, `config`, …).
- `MCEq.config` is a package with lazy platform detection, so importing it no
  longer dlopens MKL or resolves the kernel; `MCEq.download` takes the database
  helpers. Thread limits are process-wide: `config.set_mkl_threads` covers MKL
  and OpenBLAS.
- fp32 works with secant coupling on every backend, not only CUDA.
- Removed: the EM ρ-stack path, MKL BSR storage, `config.numpy_bsr_blocksize`,
  `config.mkl_bsr_blocksize`, `config.secant_blas_threads`, `secant_split` and
  `CompiledOperator.from_split`.
- **The supported Python floor is now 3.10**, and `six` is no longer a
  dependency.
