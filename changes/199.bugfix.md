Z-factors are computed as matrix rows, the form of the published definitions, and the values change. `z_factor(definition="thunman")` (Thunman, Ingelman & Gondolo 1996: Z_i = sum_j C_ij sigma_j phi_j / (sigma_i phi_i), the yield table against the nucleon flux at fixed secondary energy) applied neither the flux nor the cross-section ratio (a length-one slice) and returned the bare row sum, ~1e9 for p -> pi+; it now returns 0.033-0.044 (SIBYLL 2.3e, 100 GeV-100 TeV). `decay_z_factor` read one parent column and did not reproduce Lipari's (1993) moment int x^(-gamma-1) dN/dx dx (pi+ -> nu_mu 0.357 vs analytic 0.093); it is now the row of the decay table against a power-law parent decay spectrum E^gamma (`gamma`, new keyword, default the nucleon index of the primary model at the daughter energy) and matches the analytic two-body moments to 1e-4 on stencil-averaged tables (bin-centre tables: pi -> mu +2..4 %, their binning bias). `definition="primary_e"` is unchanged on bin-centre tables. The row form is also what stencil-averaged tables are built for; a single column of such a table is not the spectrum of one parent energy.
