Added :class:`~MCEq.geometry.density_profiles.TabulatedAtmosphere`, which runs
MCEq on a measured or reanalysed atmosphere read from a CSV table, and
:class:`~MCEq.geometry.density_profiles.TabulatedLocationCentered`, which binds
such a table to a detector position.

A table gives ``h_cm`` plus either ``rho_gcm3`` or ``T_K`` and ``p_hPa``;
comment lines, arbitrary column order, unknown columns and missing values are
all handled, and :func:`~MCEq.geometry.density_profiles.load_atmosphere_table`
returns an :class:`~MCEq.geometry.density_profiles.AtmosphereTable`.  Optional
``lat_deg``/``lon_deg`` columns turn it into a longitude/latitude grid of
columns, which ``TabulatedLocationCentered`` samples at the shower impact point
using the same impact-parameter geometry as
:class:`~MCEq.geometry.density_profiles.MSIS00LocationCentered` -- so the
azimuth angle is resolved, and with a global table upgoing zenith angles up to
180° work, where the shower developed on the far side of the Earth.  Without a
grid the single column is used for every direction and the zenith range stops
at the horizon.

A gridded table need not be global.  A regional table raises when asked for a
position it does not cover, rather than clamping to its nearest edge and
silently returning a column from somewhere else, and it interpolates across the
360°/0° seam only when its longitude axis actually closes on itself.  Because
longitudes are stored in [0, 360), a region spanning the prime meridian is
rejected at load time with an explanation instead of being read as a grid with
a hole in it.

Profiles are completed to the top of the atmosphere with an isothermal tail
fitted to their two topmost rows, or by blending into
:class:`~MCEq.geometry.density_profiles.MSIS00Atmosphere` with
``top_extension="msis00"``.  ``get_pressure`` joins ``get_density`` and
``get_temperature``, and ``calculate_density_spline`` is overridden to sample
the profile in a single vectorised pass.

Registered as the ``"Tabulated"`` and ``"Tabulated_LC"`` density models in
:meth:`~MCEq.core.MCEqRun.set_density_model`.
