`config.cuda_operator_precision = 32` runs CUDA solves in mixed precision: the off-diagonal operator values are stored in fp32 while the state and every sum stay in fp64. On the Legendre 2D release package (RTX 3090) a single solve takes 3.9 s instead of 4.45 s, with the angle-integrated spectra within 3e-7 of fp64 and the angular distributions indistinguishable from it (full fp32: 1.9 s, spectra within 1e-5, angular distributions within 1e-4 except in the 60–90° tails at 1e-4 to 1e-7 of the forward value, where they differ by up to 1 %). Default None keeps the operator in the state precision.
