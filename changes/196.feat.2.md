`config.cuda_operator_precision = 32` runs CUDA solves in mixed precision: the off-diagonal operator values are stored in fp32 while the state and every sum stay in fp64. On the Legendre 2D release package (RTX 3090) a single solve takes 3.9 s instead of 4.45 s, with the angle-integrated spectra within 3e-7 of fp64 (full fp32: 1.9 s, 1e-5, and up to 20 % in angular components eight orders below the peak). Default None keeps the operator in the state precision.
