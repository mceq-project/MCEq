Add a static Pyodide gallery template for basic atmospheric lepton fluxes, with
SIBYLL 2.3e and QGSJET-II-04 in a lossless database subset. A notebook download
button exports saved edits to clean Jupyter source entirely in the browser.
The browser runtime uses portable CORSIKA atmosphere formulas and the NumPy solver.

The configuration panel offers model/backend dropdowns and energy/zenith sliders
with an Apply button. Jupyter downloads retain the applied values as plain Python.
