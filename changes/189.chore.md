Byte-identical comparisons against stored arrays are removed from the test
suite: differences in host libraries (glibc, BLAS kernels) change the last
digits and fail such tests on otherwise equivalent machines. `tests/reference/`
compares a few lepton spectra, operator sizes and the species list within a
tolerance. The CI job with pinned NumPy/SciPy and AVX-512 disabled is removed.
Shared test helpers are in `tests/helpers/`.
