EM cascades run in 2D (Legendre) mode. 1D EM tables load into a 2D run as collinear production in every angular mode, e± get screened-Coulomb multiple scattering (``config.em_multiple_scattering``, default on with ``enable_em``), and the stiff low-energy e± columns of the sec(θ) path-elongation corner are integrated exactly in a per-column eigenbasis. Muons no longer scatter below ``config.muon_scattering_e_min`` (0.05 GeV), which only EM runs reach; there scattering plus decay made the secant step diverge.
