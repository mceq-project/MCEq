`MCEq.config` uses `MKL_NUM_THREADS`, `OMP_NUM_THREADS` or
`OPENBLAS_NUM_THREADS` when one is set in the environment. Otherwise the BLAS
thread count is `min(16, n)`, with n the CPUs available to the process
(affinity mask) rather than all cores of the host. The test suite divides the
CPUs among pytest-xdist workers in the same way.
