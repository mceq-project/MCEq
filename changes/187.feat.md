2D runs use a screened Coulomb model for muon scattering by default
(`config.muon_scattering_model = "screened-coulomb"`), computed at run time from
the composition of the medium stored in the database. It includes the
single-scattering tail. `"gaussian"` selects the previous model. Angle-integrated
muon fluxes change by less than 1e-4.
