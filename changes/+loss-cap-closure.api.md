The continuous-loss step cap (``continuous_loss_rate``) no longer counts the monotone upwind closure rows of a loss band, only the mixed-sign rows above them; the builder records the closure row count per band in ``MatrixBuilder._contloss_upwind_rows``. The cap of the 2D FLUKA configuration moves from 0.185 g/cm^2 to above ``dX_max``; users who want the previous step size set ``dX_max`` explicitly.
