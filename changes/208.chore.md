CI is leaner: pull requests run five test jobs (Linux x86 and arm64, macOS, Windows) instead of 39, while pushes to `main`, the weekly schedule and PRs labelled `full-ci` test every image at Python 3.10 and 3.14. Wheels are built by one cibuildwheel job per platform covering all CPython versions (6 jobs instead of 29), and PRs that touch the build run a single Linux wheel smoke test.
