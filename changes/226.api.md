Muon scattering rates are physics input from the database only: `MCEq.operators.scattering` reads `material_scattering/<medium>/screened_coulomb_rates` (written by mceq-maintenance-tools with `mceq_em.coulomb_scattering`, mceq-project/mceq-EM#22) and raises if a 2D database lacks it or was made for another muon mass or grid. The run-time screened Coulomb and Gaussian computations, `config.muon_scattering_model`, `config.muon_scattering_finite_nuclei` and `HDF5Backend.scattering_composition` are removed; `config.muon_multiple_scattering = False` still switches scattering off. Default runs are unchanged (they already used the table).
