`set_mod_pprod` no longer deletes the sub-diagonal entries (child bin above the parent bin) of the modified channel. `_gen_mod_matrix` set the lower triangle of the modification matrix to 0 instead of 1, and `get_matrix` multiplies by it, so any production modification removed the negative bin-average stencil entries of the v2 databases: an identity modification of p→p and n→n raised the nucleon flux at 1000 g/cm² by 7–8 % (1 TeV proton, FLUKA 2025.1 DB).
