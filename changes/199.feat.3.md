2D runs no longer spend minutes on the muon scattering rates. The default screened Coulomb model with finite nuclei costs ~l_max^2 (about 150 s for the l <= 2000 modes on 31 bins) and was evaluated at every `MCEqRun` construction and every matrix rebuild. A 2D database can now carry the rates precomputed (`material_scattering/<medium>/screened_coulomb_rates`, written by mceq-maintenance-tools from the same function, with its inputs recorded); MCEq uses them when the muon mass, `muon_scattering_finite_nuclei` and the grids match, cut to the run's energy window, and otherwise computes them once per process. The v2.0.0 2D base package and the 2D CI file carry the table; construction of a 2D run on the CI file drops from 163 s to 1.2 s, with identical operators.
